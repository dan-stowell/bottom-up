# IDEAS (each with a kill test and a status)

| # | idea | kill test | status |
|---|---|---|---|
| 1 | **Output on hugetlbfs, image laid out on 2 MiB boundaries.** The binary execs from `/dev/hugepages` when every PT_LOAD is 2 MiB-aligned in file and memory, filesz = memsz (bss in the mapping) and there are no section headers past the last segment. 55 faults instead of 28,000. | Kill if a 110 MB fill is not under 8 ms on 8 threads, or MinIO's tests do not run from it. | **Spike passed** 2026-11-13: hello (stock link `-R 0x200000`, headers patched) runs from hugetlbfs; `explore/linkos/outfile.c` fills 110 MB in 3.7 ms (tmpfs 19 ms, ext4 31-39 ms). To build: hlink `-hugetlb` layout mode. Needs `sysctl vm.nr_hugepages`. |
| 2 | Overwrite the existing output in place (no O_TRUNC, no unlink): the page-cache pages are already there. | Kill if under 10 ms saved on ext4. | Measured: 13 ms against 31-39 ms (ext4), 9 against 19 (tmpfs). Not built. Unlinking a 110 MB tmpfs file costs 11.6 ms by itself. |
| 3 | Return to the caller when the output is complete; tear the address space down in a detached child (what mold does). | Kill if exit teardown is under 3 ms once inputs are mapped sparingly. | fclink's exit costs 56-69 ms here (process minus its own total). Not built. |
| 4 | Linker's own arrays (canon/state/addr, join partitions) from MAP_HUGETLB. | Kill if anonymous-fault kernel time is under 2 ms of the link. | Not measured in hlink yet. Anonymous first touch is 4.3 M pages/s on 8 threads: 62 MB of arrays = 3.5 ms. |
| 5 | **Demand-driven resolve fused with reachability**: resolve a reference only when the flood reaches it. By-index references need nothing; content-hashed symbols (2.6 M of MinIO's 5.2 M slots) are interned in a concurrent table only when reached (about 360 k are live); by-name definitions (548 k) are indexed once; a by-name reference to a package-indexed definition builds that package's name index on first miss. | Kill if eager resolve in C is already under 2x its floor (2.4 ms), or if the lazy table's contention makes reach slower than eager resolve + reach. | Not built. Would also lower the resolve floor (not every record must be read), and FLOOR.md must then say so. |
| 6 | One packed input file instead of 1,312 archives (4 ms of opens on 8 threads). | Kill if opens overlap fully with other work. | Not built. |
| 7 | Free input pages with parallel `MADV_DONTNEED` before exit (munmap is single-threaded under the mmap lock, 9.9 M pages/s). | Kill if idea 3 lands. | Not built. |
